# Motion Studio

Un pequeño laboratorio visual de animación hecho con Python y Tkinter. No necesita paquetes externos.

## Ejecutar

Desde esta carpeta, ejecuta:

```powershell
python animaciones.py
```

## Controles

- **Órbita**, **Lluvia** y **Pulso** cambian el movimiento de las partículas.
- Elige una paleta y ajusta la velocidad con el control lateral.
- Pausa, reanuda o reinicia la escena cuando quieras.
- Pulsa en cualquier punto del lienzo para lanzar una onda.
